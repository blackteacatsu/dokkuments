## Description
Soil temperature represents the thermal state of the soil at various depths. This variable influences biological activity, seed germination, root growth, decomposition rates, and energy exchange between the land surface and atmosphere in the Amazon basin.

## Specification
Labeled as **SoilTemp_inst**, representing instantaneous soil temperature.

**Unit: $\degree\text{C}$ (degrees Celsius)**

### Dimensions
1. **time**: Temporal dimension
2. **Soil temperature profile**: Vertical depth layers

| Soil Temperature Profiles | Depth Range | Description |
| ----------- | ----------- | ----------- |
|0|0–10 cm|Surface layer|
|1|10–40 cm|Shallow subsurface|
|2|40–100 cm|Intermediate subsurface|
|3|100–200 cm|Deep subsurface|

## Applications
- Agricultural planning and crop modeling
- Soil respiration and carbon flux estimation
- Microbial activity assessment
- Permafrost monitoring (where applicable)
- Energy balance studies
- Ecosystem productivity modeling
